Settlement proof

A valid settlement starts with a confirmed Bitcoin transaction containing exactly one SATS commitment output. The output is OP_RETURN followed by a 32-byte SHA-256 digest. Its submitted preimage binds protocol tag, version, action, sat weight, Solana mint and nonce. The program rejects an unknown version, zero weight, wrong mint, malformed transaction, reused outpoint or reused nonce before it changes supply or reserve state.

No trusted signer approves settlement. Anyone may relay the same public Bitcoin evidence, but only the first valid proof can consume its outpoint and nonce. Bitcoin transactions are public, so this mechanism makes no false privacy claim. Its security boundary is explicit: Bitcoin proof of work, the tracked best-work chain, the confirmation threshold, Merkle inclusion and deterministic Solana replay protection.
